PROSPECT v0.6.1 — BUSCA GLOBAL SIMPLIFICADA

O arquivo .env já está preenchido nesta entrega.
Não é necessário criar .env.local nem copiar .env.example.

1. No PowerShell, dentro da pasta do projeto:

npm install
npm run dev

2. Abra:
http://localhost:3000

3. Em Explorar:
- escolha um país;
- escolha a região/estado quando houver;
- escolha uma cidade;
- pesquise o nicho.

Fluxo de localização:
PAÍS → REGIÃO/ESTADO → CIDADE

O Prospect usa:
- países/regiões/cidades: base mundial ODbL;
- empresas: Google Places ao vivo.

O bairro/sublocalidade ainda pode aparecer nos detalhes do endereço quando o Google informar esse dado, mas não existe mais filtro de bairro.

BANCO LOCAL (quando necessário):
docker compose up -d postgres

VERIFICAÇÃO DE SEGURANÇA:
npm audit
npm audit --omit=dev

IMPORTANTE:
- O .env contém credenciais reais e está no .gitignore.
- Não publique o .env nem este ZIP em repositórios públicos.
